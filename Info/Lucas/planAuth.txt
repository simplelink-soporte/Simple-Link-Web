# Plan de Separación de Autenticación - Simple-link

## 1. Análisis del Estado Actual

### Problemas Identificados
1. Mezcla de sesiones entre panel admin y links de clientes
2. Uso compartido de instancias Supabase
3. Conflictos en localStorage y cookies
4. Manejo de roles no diferenciado
5. Interferencia en la carga de sedes

### Estructura Actual
1. Tabla `users` (Auth)
   - Manejo de roles básico
   - Triggers para creación de usuarios
   - Metadatos de usuario y aplicación

2. Hooks de Autenticación
   - `useAdminAuth`: Panel administrativo
   - `useClientAuth`: Links de clientes
   - `useAuth`: Wrapper para cliente
