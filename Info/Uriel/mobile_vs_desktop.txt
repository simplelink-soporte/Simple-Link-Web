## 📋 Diagnóstico del Problema

### Problema Principal

```typescript

  const { useStoredCards } = await import('@/hooks/useStoredCards');

  // Obtener customerInfo usando el hook

  const stripeContext = useStripe();
  // ...
}
```

Los hooks de React **deben ser importados en la parte superior del archivo** y llamados de forma incondicional en el nivel superior del componente. No pueden ser importados dinámicamente ni llamados dentro de funciones o bloques condicionales.
