# Estrategia de Implementación: Sistema de Tarjetas Guardadas con Stripe Connect

## 1. Estado Actual y Contexto

### 1.1 Componentes Existentes
- `stripe-customer.service.ts`: Maneja la creación y gestión de customers
- `CardSetupForm.tsx`: Formulario para guardar tarjetas
- `PaymentMethodModal.tsx`: Modal para gestionar métodos de pago
- `StripeProvider.tsx`: Proveedor de contexto de Stripe

### 1.2 Flujo Actual
1. Usuario accede al formulario de pago
2. Se obtiene el stripeAccountId del club
3. Se crea/obtiene un customer usando stripe-customer.service.ts
4. Se intenta guardar la tarjeta

## 2. Requisitos y Preferencias del Cliente

### 2.1 Requisitos Funcionales
- Permitir guardar múltiples tarjetas (máximo 10)
- No requerir verificación 3D Secure
- Enfoque en pagos únicos (no recurrentes por ahora)
- Guardar tarjetas sin necesidad de realizar un pago inmediato

### 2.2 Requisitos Técnicos
- Usar modo desarrollo con variables de entorno (.env.local)
- Mantener compatibilidad con futura autenticación
- Seguir el flujo de Stripe para "Save directly without charging"

### 2.3 Consideraciones de UX
- Proceso simple y directo
- Feedback claro al usuario
- Manejo de errores amigable

## 3. Estrategia de Implementación

### 3.1 Modificaciones Necesarias

#### A. Base de Datos
```sql
-- Agregar campo para contar tarjetas guardadas
ALTER TABLE stripe_customers
ADD COLUMN IF NOT EXISTS saved_cards_count integer DEFAULT 0;

-- Trigger para actualizar contador
CREATE OR REPLACE FUNCTION update_saved_cards_count()
RETURNS TRIGGER AS $$
BEGIN
  UPDATE stripe_customers
  SET saved_cards_count = saved_cards_count + 1
  WHERE stripe_customer_id = NEW.customer;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

### 3.2 Flujo de Guardado de Tarjetas

1. **Preparación**:
```typescript
// 1. Obtener/Crear Customer
const customer = await stripeCustomerService.getOrCreateCustomer(
  userId,
  stripeAccountId
);

// 2. Verificar límite de tarjetas
if (customer.saved_cards_count >= 10) {
  throw new Error('Límite de tarjetas alcanzado');
}
```

2. **Setup Intent**:
```typescript
// 3. Crear Setup Intent
const setupIntent = await stripe.setupIntents.create({
  customer: customer.stripeCustomerId,
  payment_method_types: ['card'],
  usage: 'off_session'
}, {
  stripeAccount: stripeAccountId
});
```

3. **Confirmación**:
```typescript
// 4. Confirmar Setup Intent
const result = await stripe.confirmCardSetup(clientSecret, {
  payment_method: {
    card: elements.getElement(CardElement)!,
  }
});
```

### 3.3 Manejo de Errores

```typescript
const handleSetupError = (error: any) => {
  const errorMessages = {
    card_error: 'Error con la tarjeta',
    validation_error: 'Error de validación',
    rate_limit: 'Demasiados intentos, espera un momento',
    invalid_request: 'Solicitud inválida'
  };

  return errorMessages[error.type] || 'Error al procesar la tarjeta';
};
```
